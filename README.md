# The Grafinity - Personal Portfolio Website

Professional portfolio website for **Sajidul Islam Mahad**, founder of **The Grafinity**.

## Features
- **Modern Dark Luxury Aesthetic**: Sleek black background with white typography and striking neon green accents (`#00FF00`).
- **Fully Responsive**: Optimized for mobile devices, tablets, laptops, and large desktop displays.
- **Easy Edit System**: Centralized configuration block inside `script.js` to modify text, branding, social links, services, portfolio items, and testimonials instantly.
- **Interactive Project Modal**: Clicking any portfolio project opens a full high-resolution preview.
- **GitHub Pages Ready**: Zero backend required. Host directly for free on GitHub Pages.

## How to Deploy on GitHub Pages
1. Create a repository named `thegrafinity.github.io` (or any repository name with GitHub Pages enabled).
2. Upload all files maintaining the exact folder structure (`index.html`, `style.css`, `script.js`, and the `images/` folder).
3. Ensure your images are inside the `images/` directory.
4. Go to your GitHub Repository Settings > **Pages**, and set the source branch to `main` / `root`.
5. Your live portfolio will be available at your GitHub Pages URL!
